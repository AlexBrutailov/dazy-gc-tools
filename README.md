# DAZY GC Process Tools — v0.3.0

Исправления после живого теста на копии процесса `2592961`.

## Версии

- Safety Guard `v0.2.1`
- Fast Editor `v1.5.1`
- Minimap `v0.6.0` (без изменений)
- SMART Launcher `v0.5.1 BETA`

## Исправлено

### 1. Launcher снова сворачивается в круг DAZY

В прошлой версии кнопка использовала CSS-класс `collapse`, который конфликтовал
с Bootstrap GetCourse и мог скрываться штатными стилями. Теперь используется
собственный класс `gcptl-collapse-btn`.

Сворачивать меню можно:
- кнопкой `−` справа в заголовке;
- кликом по самому заголовку `DAZY`.

### 2. Возвращён полноценный режим изменения связей

Fast Editor в managed UI теперь монтирует компактный контекстный интерфейс
прямо внутрь Launcher.

После `Изменить связи блоков`:
1. нажмите исходный блок;
2. в Launcher появятся его выходы и текущие назначения;
3. выберите нужный выход;
4. нажмите целевой блок;
5. подтвердите подключение/переподключение.

Отдельное постоянное окно Fast Editor не появляется.

### 3. Undo группового переноса больше не запускает полный fullSync

Алгоритм:
1. Launcher заранее показывает `Отмена выполняется, пожалуйста, подождите…`;
2. Safety Guard возвращает координаты через `move-scripts`;
3. Guard повторно читает сервер и ждёт подтверждения координат;
4. Fast Editor точечно обновляет только восстановленные блоки в DOM;
5. jsPlumb перерисовывает только затронутые блоки.

Сообщение об успехе появляется только после серверной проверки и локального
обновления.

Это должно быть существенно легче, чем полная синхронизация 700+ блоков.
