# DAZY GC Process Tools — v0.2.0

Обновлённая архитектура инструментов процессов GetCourse.

## Версии

- Safety Guard `v0.2.0`
- Fast Editor `v1.5.0`
- Minimap `v0.6.0`
- SMART Launcher `v0.5.0 BETA`

## Что изменилось

### Один интерфейс вместо трёх окон

Safety Guard и Fast Editor работают в `managedUi` и не создают собственные
постоянные панели. Основное управление находится в Launcher.

Minimap остаётся отдельной панелью, но её интерфейс сокращён.

### Роли

В Launcher есть:

```js
allowedUserIds: [ ... ],
adminUserIds: [ ... ],
allowedAccountIds: [ ... ]
```

Пользователь из `allowedUserIds`, но не из `adminUserIds`, получает рабочую
упрощённую панель.

Админ получает ту же панель + скрываемый раздел `Админ-инструменты`.

### Рабочая панель

- Мини-карта
- Изменить связи блоков
- Быстрое перемещение блоков
- Разовое разрешение большого переноса появляется только при необходимости
- Отменить последний перенос группы

Отдельной кнопки «Сохранить» нет: изменения GetCourse сохраняются в момент
самого действия. Полная синхронизация не является сохранением.

### Админ-инструменты

- Синхронизировать схему
- Проверить координаты
- Обновить точку восстановления
- Восстановить координаты
- Проверить совместимость

### Safety Guard

- блокирует случайный перенос группы больше лимита;
- позволяет одноразово разрешить большую группу;
- хранит baseline процесса в localStorage;
- сохраняет snapshot не только большой разрешённой группы, но и обычных
  групповых переносов из 2+ блоков;
- позволяет откатить последний групповой перенос после F5/перезапуска браузера.
